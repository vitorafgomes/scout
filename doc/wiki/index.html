Engineering Wiki

Scout Wiki

The LLM-maintained engineering wiki for Scout, an open-source read-only chatops assistant built on Microsoft Semantic Kernel and .NET 10. This wiki is the cheap context layer: start here, follow links into services, invariants, and decisions before reaching for the code.

66 pages 11 services 13 ADRs 6 invariants
The descriptive-write / read-only invariant. No feature, adapter, plugin, or knowledge operation may execute a mutating action against an external system. See No Executive Writes and ADR 0009.
How to use this wiki

Each page carries a metadata header (type, status, version, date, sources) and a Related footer linking neighbouring pages. The About page explains the page-type taxonomy and the wiki conventions. The companion single-page Architecture & Project Reference lives one level up.
