## Contract

- **Configuration keys:** `Scout:Llm:Provider`; one block per provider under `Scout:Llm:<Provider>` with `ApiKey`, `Endpoint`, `Chat:Model`, `Embeddings:Model` (AzureOpenAI uses `Chat:Deployment` and `Embeddings:Deployment`; Anthropic has only `ApiKey`, `Chat:Model` (default `claude-opus-5-5`) and `Chat:MaxOutputTokens` (default 64,000), on its own `AnthropicChatOptions`); for narration and scene pictures, `Scout:Llm:OpenAI:SpeechModel` (default `gpt-4o-mini-tts`) and `Scout:Llm:OpenAI:ImageModel` (default `gpt-image-2.5-sunburst`, since OpenAI shut down `gpt-image-1` on 2026-10-23), a blank value meaning the default (`src/Scout.Llm/Configuration/LlmOptions.cs:84`, `:87`), `Scout:Llm:OpenAI:ImageQuality` (default `medium`; `low` or `medium`, anything else refused when the factory is built with a sentence naming them) (`:90`), and `Scout:Llm:OpenAI:MediaOnCustomEndpoint` (default false) (`:96`); `Scout:Llm:AzureOpenAI:SpeechDeployment` and `Scout:Llm:AzureOpenAI:ImageDeployment`, empty by default, so Azure OpenAI gets no media service until the owner names a deployment (`:163`, `:166`), and `Scout:Llm:AzureOpenAI:ImageModel` (default `gpt-image-2.5-sunburst`, for the same reason), the model behind that deployment (`:169`); none of them is in `appsettings.json`, which carries no OpenAI or Azure OpenAI block; Ollama also reads `Chat:ContextLength` (default 16384, at least 4096; see Provider `Ollama`), `Embeddings:MaxBatchSize`, `Embeddings:ExpectedDimensions`, `Embeddings:HttpTimeoutSeconds`. Options types: `src/Scout.Llm/Configuration/LlmOptions.cs:13`. The read-only guard reads `Scout:Guard:TypeSafe` with `ApiKey` (empty: guard off), `Model` (`jev-latest`), `Endpoint` (`https://api.typesafe.ai`) and `Threshold` (0.5) (`src/Scout.Llm/Configuration/TypeSafeGuardOptions.cs:7`), and `Scout:Features:GrantedWrites`, a comma-separated list of the feature ids whose write grant the owner turned on, which the desktop sets as `SCOUT__FEATURES__GRANTEDWRITES` when it starts the worker (`src/Scout.Llm/Configuration/FeatureGrantsOptions.cs:8`, bound at `src/Scout.Llm/LlmServiceCollectionExtensions.cs:72`).
- **A key over plain http:** the endpoint checks accept `http` as well as `https`, so the owner can point a provider at a local or test server. When AzureAIInference, AzureOpenAI, HuggingFace, Mistral, OpenAI or OpenRouter is built with an `http` endpoint whose host is not this machine (`localhost`, `127.0.0.0/8` or `::1`), it logs one warning: "The <provider> provider sends its API key over plain http to <host>, which is not this machine; an https endpoint keeps the key encrypted." The warning names the provider, the scheme and the host, and nothing else: no key, no user-info, no port, path or query. The provider is still built and works as before. An `https` endpoint and a loopback `http` endpoint log nothing; Ollama sends no key and is not checked, so its default `http://localhost:11434` logs nothing either. The six constructors share one check (`src/Scout.Llm/Providers/PlainHttpEndpoint.cs:8`, called at `src/Scout.Llm/Providers/Mistral/MistralLlmProviderFactory.cs:88`), and each takes an optional logger that the container fills; OpenAI checks its chat endpoint and an embeddings endpoint set apart from it, so an embeddings endpoint inherited from the chat one warns once (`src/Scout.Llm/Providers/OpenAI/OpenAILlmProviderFactory.cs:135`), and OpenRouter checks its embeddings endpoint, the only one it is given (`src/Scout.Llm/Providers/OpenRouter/OpenRouterLlmProviderFactory.cs:121`). An endpoint a constructor refuses is named in its `ArgumentException` by scheme, host and port, and by path too when it is http or https, never by its user-info or query (`src/Scout.Llm/Providers/PlainHttpEndpoint.cs:21`, `tests/Scout.Llm.Tests/Providers/PlainHttpEndpointWarningTests.cs:164`, over all seven providers that take an endpoint). Tests: `tests/Scout.Llm.Tests/Providers/PlainHttpEndpointWarningTests.cs:57`, `:74`, `:92`, the OpenAI and OpenRouter embeddings endpoints `:138` and, through `AddScoutLlm`, `:109`.
- **External boundaries:** the chosen provider's HTTP API, including, for OpenAI and Azure OpenAI, its speech and image endpoints when the operator produces media (Ollama on localhost by default, `src/Scout.Llm/Configuration/LlmOptions.cs:250`; hosted APIs otherwise), and, only when a TypeSafe key is set, `POST /v1/systemone` on TypeSafe (`src/Scout.Llm/Guard/TypeSafeClient.cs:25`), which receives the latest user message and up to 12 messages before it, including Scout's own replies. A live translation goes to the provider's own chat service and bypasses the read-only guard: the guard classifies a request before functions can run, and a translation offers no function and has no reach (settings with a 400-token cap and no function choice, no kernel), so TypeSafe never receives a transcript line, and a line that reads as a write intent comes back translated, not refused (`tests/Scout.Llm.Tests/LiveTranslatorTests.cs:134`).
