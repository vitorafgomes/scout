- **Origin of a turn** ([[pages/decisions/0033-channel-operator-architecture]]): `ChatMessage.OriginReference`, an init-only opaque `<adapter>:<payload>` string the adapter fills (`src/Scout.Conversation/Abstractions/ChatMessage.cs:60`); `ChatOrigin.Current`, the reference of the turn on the current async flow (`src/Scout.Conversation/Abstractions/ChatOrigin.cs:20`); `ChatOrigin.IsOwner`, true only while a turn of Scout's owner runs: the local quick-ask user, or an allowed chat user listed in `Scout:Access:OwnerUserIds` (`src/Scout.Conversation/Abstractions/ChatOrigin.cs:27`), which the operator's owner-only functions read ([[pages/services/operator]]); `ChatOrigin.Remember(mark, lifetime)` and `ChatOrigin.Remembers(mark)` (`src/Scout.Conversation/Abstractions/ChatOrigin.cs:45`, `:79`): a mark is kept for the rest of the running turn and, when the turn has a conversation key, for `lifetime` in every later turn with the same key, whatever its origin reference, measured on the conductor's clock. The conductor enters each turn with `ChatOrigin.Enter(originReference, isOwner, time, conversationKey)` (`src/Scout.Conversation/Abstractions/ChatOrigin.cs:102`), the key coming from the registered `IConversationKeyProvider`, the same one the memory uses: channel and sender (`src/Scout.Conversation/Memory/ConversationKeyProvider.cs:19`). Every turn the conductor enters has a key, Teams' too; only a turn entered with a null key keeps its marks until it ends, which no caller does today. The marks kept past their turn live in one process-wide store under a lock, at most 256 (`ChatOrigin.KeptCap`): each write first drops the expired ones and, when the store is still full, the one closest to expiring. The operator's project-state read fills it for 10 minutes, so its change functions run only after a state read in the same conversation within 10 minutes (`tests/Scout.Operator.Tests/YouTubeOperatorPluginTests.cs:615`); `IOriginNotifier.PostAsync(string originReference, string text, CancellationToken ct)` returning `Task<bool>` (`src/Scout.Conversation/Abstractions/IOriginNotifier.cs:14`), implemented by `OriginNotifier` (`src/Scout.Conversation/OriginNotifier.cs:11`, registered at `src/Scout.Conversation/ConversationServiceCollectionExtensions.cs:51`) over the `IOriginPoster` each adapter registers, with `Kind` and `PostAsync(string payload, string text, CancellationToken ct)` (`src/Scout.Conversation/Abstractions/IOriginPoster.cs:17`).
- **Transcription:** `IAudioTranscriber.TranscribeAsync(Stream, string contentType, CancellationToken)` (`src/Scout.Conversation/Abstractions/IAudioTranscriber.cs:8`); optional constructor dependency of the conductor, registered by the host only when a model exists. Its second member, `TranscribeSegmentsAsync(Stream wav, TimeSpan maxDuration, CancellationToken)` (`:20`), yields the `TranscribedSegment(TimeSpan Start, TimeSpan End, string Text)` records (`:24`) of a 16 kHz mono WAV recording up to the caller's limit; the conductor never calls it, the YouTube operator does for the owner's own video ([[pages/services/operator]]). `TranscriptionBusyException` (`:27`) is what `TranscribeAsync` throws when another transcription held the model too long, in the Whisper transcriber 30 seconds behind a recording ([[pages/services/transcription-whisper]]). Live: `ILiveTranscriber.Start(Func<LiveTranscript, Task> onEvent, CancellationToken)` returns an `ILiveSession` with `FeedAsync(ReadOnlyMemory<byte> pcm16, CancellationToken)` and `StopAsync(CancellationToken)`; `LiveTranscript(string Text, bool Final)` carries a partial or the final text of an utterance (`src/Scout.Conversation/Abstractions/ILiveTranscriber.cs:7`). It is vendor-free, registered under the same model-file condition, and consumed only by [[pages/services/adapter-local]], as an optional constructor dependency; the conductor does not use it.
- **Screenshot text:** `IScreenTextReader.ReadAsync(ReadOnlyMemory<byte> jpeg, CancellationToken)` answers the text on a screenshot, never empty, and throws when it cannot be read (`src/Scout.Conversation/Abstractions/IScreenTextReader.cs:7`). - **Configuration keys:** `Scout:Conversation` (`SystemPrompt`, `Temperature`, `MaxTokens`; `src/Scout.Conversation/Routing/LlmStreamingRouterOptions.cs:7`). `MaxTokens`, 800 in the console host's `appsettings.json`, caps a plain chat answer only.
