## Public contract

- **Worker gate over gRPC:** `RequestWrite` (`src/Scout.Host.ControlPlane/Services/WorkerGateGrpcService.cs:35`) answers the decision as the lowercase `allowed`, `queued` or `refused`, the reason, and the action id when queued; since 2026-11-12 (issue #323) it goes through `WriteGateService.RequestToRunAsync` (`src/Scout.Host.ControlPlane/Services/WorkerGateGrpcService.cs:39`), so an allowed reversible write is in the write log as `started` before the worker runs it and the answer's `action_id` is that entry's id, which the worker's `RecordWrite` names (`tests/Scout.ControlPlane.Tests/Integration/WorkerGateGrpcTests.cs:294`), and a `started` entry that cannot be written fails the call with the log's exception, `UNKNOWN`, so the worker runs nothing (`:376`); no `.proto` field changed, `action_id` was already optional on the answer and the record; and since 2026-11-11 queues an irreversible action in the request's optional `group_id` on its optional `repository`, as the worker sent them; `CloseWriteGroup` (`:62`) reports that a request ended: it stamps the group's actions closed, decides none and answers how many the group holds, a blank id `INVALID_ARGUMENT`, and the desktop token gets `PERMISSION_DENIED` on it (`tests/Scout.ControlPlane.Tests/Integration/WorkerGateGrpcTests.cs:191`, `:248`). `RecordWrite` (`src/Scout.Host.ControlPlane/Services/WorkerGateGrpcService.cs:77`) answers `FAILED_PRECONDITION` with the gate's message when the write could not have been permitted (`:96`). `NextApprovedAction` (`src/Scout.Host.ControlPlane/Services/WorkerGateGrpcService.cs:157`) answers the claimed action, mapped like a queued one with `status` `executing`, or an empty response when none is due or the owner has not granted YouTube; it never answers `PERMISSION_DENIED` for a missing grant.
