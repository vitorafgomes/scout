## Overview

> The part of [[pages/services/desktop-ui]] that lets the owner ask Scout from anywhere on the desktop; the worker side is [[pages/services/adapter-local]].

The owner's way to ask Scout from anywhere on the desktop, without a chat platform ([[pages/decisions/0028-local-quick-ask-assistant]]).

- **Shortcut.**
  - `registerQuickAsk` (`ui/packages/main/src/quick-ask/quick-ask.ts:711`, called at `ui/packages/main/src/main.ts:1092`) registers `CommandOrControl+Alt+Space`, or the shortcut stored under the main-only vault key `quick-ask.shortcut` (`ui/packages/main/src/vault/safe-storage-vault.ts:23`), with `globalShortcut`. `disposeAll`, run by the single `before-quit`, unregisters it (`ui/packages/main/src/main.ts:317`).
  - Settings, "Floating button and quick ask", shows the saved shortcut as keycaps under "Quick-ask shortcut" (`ui/packages/renderer/src/app/wizard/settings/settings.component.ts:348`), CommandOrControl as Ctrl, or Cmd on a Mac, and Alt as Option there (`keycapsOf`, `ui/packages/renderer/src/app/wizard/settings/quick-ask-shortcut.ts:105`). **Record shortcut** (`ui/packages/renderer/src/app/wizard/settings/settings.component.ts:362`, `toggleRecording`, `:964`) takes the next key combination pressed on it (`captureKey`, `:982`): a modifier alone keeps it waiting; a key with no modifier, or with Shift alone, is refused with main's own sentence and it keeps waiting; Esc ends it with the saved shortcut back; Tab and Shift+Tab move the focus as usual and leaving the button ends it, both unchanged; a whole combination becomes the keycaps and the shortcut Save sends, and is announced on a polite status line, as "Recording. Press the new shortcut, or Esc to cancel." is when it starts (`:388`). No key it takes reaches the page, and the release of one is kept from the button too, so Space cannot press Record shortcut again (`releaseKey`, `:1009`); outside a recording no key is touched. `captureShortcut` (`ui/packages/renderer/src/app/wizard/settings/quick-ask-shortcut.ts:79`) writes the accelerator in the names main stores, `CommandOrControl` for Ctrl, or for Cmd on a Mac, then `Control` (a Mac's Ctrl), `Super`, `Alt`, `Shift` and the key. A letter is named by the character the layout gives it (`event.key`) on Linux and Windows and by its position (`event.code`) on a Mac, because Chromium registers a global shortcut by the character's key on X11 and Windows and by key position on macOS; every other key is named by its position, so Shift, AltGr and Option never change it; a key Electron has no name for is refused. While it records, the renderer asks main to let the global shortcut go, `scout:local.suspendShortcut` with `suspended: true`, and to take it back when the recording ends, including when Settings closes (`suspendShortcut`, `ui/packages/main/src/quick-ask/quick-ask.ts:1248`); main also watches the page that asked and takes the shortcut back if it is closed, crashes or reloads (`destroyed`, `render-process-gone`, `did-start-navigation`, `RECORDER_GONE`, `:171`, `takeShortcutBack`, `:1236`), so a lost renderer never leaves it let go: pressing the saved shortcut then reaches the page and is recorded instead of opening quick ask; a take-back registers it again only if it was registered before, and one the system refuses leaves `registered` false, never an error; a save made meanwhile registers the new one. Only the main window may call it (`SHORTCUT_GUARDS`, `ui/packages/main/src/ipc/sender-check.ts:136`, applied to the quick-ask module's handlers at `ui/packages/main/src/main.ts:1093`); any other sender gets `ipc/not-main-window`. Save sends the recorded accelerator through `scout:local.setShortcut` (`saveShortcut`, `ui/packages/renderer/src/app/wizard/settings/settings.component.ts:1038`); a refused or failed save shows its reason and puts the keycaps back to the saved shortcut. `scout:local.getShortcut` and `setShortcut` answer the accelerator, `registered` (what `globalShortcut.register` returned) and `hint` (`shortcutStatus`, `ui/packages/main/src/quick-ask/quick-ask.ts:1202`). On Wayland the hint is "Your desktop (Wayland) does not let apps register global shortcuts. Add a custom shortcut in your system settings that runs: <command>", the command being the `APPIMAGE` path or the running executable followed by `--ask`, quoted when the path holds a space (`ui/packages/main/src/quick-ask/quick-ask.ts:1200`); main passes `process.execPath`. Settings shows it under the shortcut while Record shortcut stays usable (`ui/packages/renderer/src/app/wizard/settings/settings.component.ts:395`); elsewhere it is null. Tests: `ui/packages/renderer/src/app/wizard/settings/settings.component.spec.ts` ("Settings: Record shortcut"), `ui/packages/renderer/src/app/wizard/settings/quick-ask-shortcut.spec.ts`, `ui/packages/main/test/quick-ask.test.ts:1762` and the cases after it (the page gone, an ended recording leaving no watch, dispose), `ui/packages/main/test/sender-check.test.ts:142`.
  - Main registers the new shortcut before it releases the old one. A `false` from `register` keeps the old shortcut and returns "That shortcut is taken"; an accelerator `register` throws on also keeps the old one (`ui/packages/main/src/quick-ask/quick-ask.ts:1294`). Before `register`, `shortcutRefusal` (`:625`, called at `:1281`) refuses, case-insensitively and keeping the old shortcut, an accelerator with no modifier (a letter, Space, a bare F-key) with "\"<accelerator>\" has no modifier, so it would fire whenever you type it; add Ctrl, Alt, Super or Cmd.", one whose only modifier is Shift (Shift+A types a capital) with "\"<accelerator>\" has no modifier but Shift, so it would fire whenever you type it; add Ctrl, Alt, Super or Cmd.", and one the system reserves with "\"<accelerator>\" is reserved by the system for <use>; choose another.": Ctrl or Cmd, in any of Electron's spellings, alone with C (copy), V (paste), X (cut), Z (undo), A (select all), Q (quitting an app), W (closing a tab or window) or Tab (switching tabs or windows), Alt+F4 (closing a window), Alt+Tab (switching windows), and Super or Meta alone (opening its launcher). A stored shortcut that is now refused is not registered at startup: main falls back to the default, stores it, and adds a notice turn, "Your quick-ask shortcut <old> is no longer allowed; it was reset to CommandOrControl+Alt+Space." (`ui/packages/main/src/quick-ask/quick-ask.ts:1177`). Tests: `ui/packages/main/test/quick-ask.test.ts` ("refuses %s, a shortcut with no modifier or one the system reserves, with a sentence naming why, and keeps the old one", "accepts %s, which has a modifier and is not reserved", "a stored shortcut %s that is now refused is not registered at startup: the default is, it is stored, and a notice says so").
