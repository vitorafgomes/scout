## Public contract

- **Entry point:** `src/Scout.Host.Console/Program.cs`. `ConsoleCommand.Parse` selects run or `index <project>` (`src/Scout.Host.Console/ConsoleCommand.cs:22`); the index path builds a minimal graph (`src/Scout.Host.Console/Program.cs:14`) and runs the command through `IndexEntryPoint.RunAsync(IHost, project)` (`src/Scout.Host.Console/Program.cs:26`, `src/Scout.Host.Console/IndexEntryPoint.cs:69`), which hooks the host's lifetime to Ctrl+C, SIGTERM and SIGQUIT without starting any of the host's services (the project watcher among them) and passes `ApplicationStopping` to the run, so a stop ends the run at its next await, between files or inside an embedding call or a store write, logs one warning, "Indexing of project '<name>' was stopped before it finished.", and exits 1 (since 2026-11-11; `tests/Scout.Host.Console.Tests/IndexHostOpenAIEmbeddingsTests.cs:272`, which stops the host's lifetime during an embedding call; that Ctrl+C, SIGTERM and SIGQUIT reach `StopApplication` is the console lifetime's own behaviour and no test raises a signal). A stop between the vector write and the text write leaves the gap [[pages/roadmap/followups]] records for a re-index that stops there. Before, the command ran on `CancellationToken.None` and Ctrl+C killed the process wherever it was.
