## Voice model on the Desktop card

The Desktop panel shows one voice line and the Desktop card's fact is the same line (`sc-desktop-voice`, `ui/packages/renderer/src/app/features/desktop-voice.component.ts:148`, `line` `:182`, placed in the panel at `ui/packages/renderer/src/app/features/features.component.ts:250`), because voice messages and live transcription need a Whisper model on this computer and Ollama is not needed for it. One place manages the models, Models → Transcription; the card and its panel only ask or point there.

- **The line** (`ui/packages/renderer/src/app/features/desktop-voice.component.ts:225`): "Voice model: <variant> installed" from `scout:whisper.listInstalled` (verified files only; the selected transcription model when it is installed, otherwise the first in the Transcription screen's order; while the worker has not loaded a model yet, as right after a download whose restart is still waiting, main answers no model in use and the line names the saved choice when it is installed, else the first verified model, `refresh`, `:230`), "Voice model: not installed" with Download, "Downloading the <variant> voice model... N%" with a progress bar from `scout:whisper.downloadProgress` for that request id, or "Could not download the <variant> voice model: <reason>" with Retry, which downloads the same variant again. Since 2026-11-08 a list that cannot be read is unknown, not "not installed": the line says "Scout could not read the voice models." with Try again, which reads main's answer again, and offers no Download. A download cancelled from any window (main's rejection carries `whisper/download-cancelled`) is not a failure: the card reads main's answer again and shows "not installed" with Download. "Manage in Models, Transcription" always links to `/llm?tab=transcription` (`:107`).
- **Download** (`:201`) opens "Download a voice model?" (`askVoiceModel`, `ui/packages/renderer/src/app/features/voice-model-dialog.component.ts:213`): "Voice messages and live transcription run on this computer with a Whisper model; nothing is sent to the cloud.", one radio row per model of main's pinned table, in main's order with its exact size (`:195`; "Scout could not list the voice models: <reason>" and no rows when main cannot give it, `:46`), with its name, download size and memory, its note, Recommended on Base and Installed (not selectable) on a model already here, and Not now, focused (`:86`), and Download. The pick goes to `scout:whisper.downloadModel`, the same pinned download Models → Transcription uses, and on success `LocalModelsStore.markDownloaded`, so the first Whisper model becomes the transcription model.
- **At the first use of voice** - the Desktop card has no switch, so the same dialog opens when voice is first needed: the quick-ask microphone or Space, Listen, System audio or Meeting in quick ask, and the Chat microphone, while main reports no verified Whisper model (`VoiceModelAsk`, `ui/packages/renderer/src/app/features/voice-model-ask.ts:17`; the check `allowsVoice`, `:53`, is synchronous so a press and its release keep their order). The voice does not start under the dialog; Download fetches the pick and the window's status line says "Downloading the <variant> voice model... N%", then "The <variant> voice model is installed." or "Could not download the <variant> voice model: <reason>", and nothing when the download was cancelled from any window; Not now is kept in that window's memory until it reloads, so the next use starts the voice without asking. When main cannot say what is installed the voice starts and nothing is asked.
