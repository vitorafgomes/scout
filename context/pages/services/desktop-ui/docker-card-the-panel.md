- **The panel** (`ui/packages/renderer/src/app/features/docker-card.component.ts:910`), on `--sc-*` tokens, `sc-icon` and Angular Material (slide toggle, buttons, progress bar): the panel's description is the opening sentence "This computer needs nothing but Docker. ..." and its header and the Docker card carry the status chip (Not installed, Installed, not running, Running · Docker <version>, or Unknown when the bridge fails, `chipLabel`); the body opens with a status line, "How to install Docker" (`https://docs.docker.com/get-started/get-docker/`, on the openExternal allow-list, `ui/packages/main/src/ipc/app.ts:21`) and Refresh; then five sections, each a disclosure button with `aria-expanded` and `aria-controls`: what Scout uses Docker for (ADR 0043's five uses), the pinned images grouped by stack, each group with its count ("Java (Maven): 1 of 5 downloaded", `groups`, `ui/packages/renderer/src/app/features/docker-card.component.ts:1010`), its own Download and its progress (`download(stack)`, `:1187`), and "Download images" (`downloadNeeded`, `:1229`): with no repository record it stays disabled with "Download images fetches only what the repositories Scout has read need, and Scout has not listed them yet. ..." (`:57`); with records it fetches the one image each repository needs and Docker lacks (`neededMissing`, `:986`: deduplicated, in the repositories' order, a refused repository skipped because it has no image), one `scout:docker.pullImage` at a time, with "Downloading i of n: <image>" and its bar, the first failure stopping the rest with main's sentence and "The other N images were not downloaded."; its help then says what it does (`:61`); it is disabled while Docker is not running, during any download, and when nothing is missing, then saying "Every image your repositories need is downloaded." (`:65`). Docker Hub limits anonymous pulls and the Java images are several hundred MB each, which is why it never fetches more. Then Repositories, the work folder with Clear behind the shared confirmation (Cancel focused), its line "<size> used · the logs of <n> runs; each run's copy of the code is deleted after it" ("the logs of 1 run" for one, and without the count when the folder holds no run record), or "Empty · run logs are deleted" (`folderSize`, `ui/packages/renderer/src/app/features/docker-card.component.ts:1048`), because the sandbox deletes each run's folder after the run whatever happened ([[pages/services/sandbox]]), and Last run.
