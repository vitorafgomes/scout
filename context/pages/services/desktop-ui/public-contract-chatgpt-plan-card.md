## Public contract

- **ChatGPT plan card** - the card is titled "ChatGPT plan", as the prototype names it; its description keeps "Sign in with your ChatGPT Plus or Pro plan." Every place that names the provider reads it from one map (`PROVIDER_CARD_NAMES`, `ui/packages/renderer/src/app/core/llm-config.store.ts:68`, through `providerLabel`): the card title and logo name, the Models group, the top bar, the quick-ask status and translation lines, and the restart messages. ChatGPT plan signs in through the system browser with OpenAI's Sign in with ChatGPT ([[pages/decisions/0018-chatgpt-plan-sign-in]]): the main process runs the OAuth flow (`ui/packages/main/src/oauth/chatgpt-auth.ts:77`), keeps the session in main-only vault keys (`ui/packages/main/src/vault/safe-storage-vault.ts:6`), refreshes it, and writes the access token to a 0600 file the worker reads; the renderer works through `scout:chatgpt.signIn`, `listModels`, `cancelSignIn`, `signOut` and `status` (`ui/packages/shared/src/ipc-contract.ts:11`). While its status is still being read the card shows two skeleton bars and "Checking your ChatGPT sign-in..." as a status, and no sign-in. The card offers Continue with ChatGPT, Cancel while waiting for the browser, "Choose a model", an outlined pill to Models, Analysis, while plan usage is granted, and Sign out, a text button in the accent; it has no model select and does not load the model list. A signed-in plan with plan usage counts as a connected cloud provider for the rule above (`ui/packages/renderer/src/app/core/llm-config.store.ts:428`): The card reads In use, with one line "<account> · answering with <model>" and the 2 px accent border of the card in use, only while it is signed in with plan usage and is the provider in use; Sign out is disabled while another provider action runs and closes any open key form. Signing in while no cloud provider is in use makes it the one in use with `gpt-5.6-luna`, also when another action was still running when the sign-in finished (it waits for that action first) (`ui/packages/renderer/src/app/sources/sources.component.ts:1646`), and signing out while it is in use switches to another connected cloud provider or to `None` through the same path as Disconnect (`:1677`, `ui/packages/renderer/src/app/core/llm-config.store.ts:438`).
