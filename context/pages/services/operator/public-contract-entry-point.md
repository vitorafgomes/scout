## Public contract

- **Entry point:** `AddYouTubeOperator(IServiceCollection)` (`src/Scout.Operator/OperatorServiceCollectionExtensions.cs:25`). The caller registers an `IOperatorControlPlane`, the YouTube client and the origin notifier first, and `AddScoutLlm` supplies the kernel and `MediaCapabilities`; [[pages/services/host-console]] does that only when YouTube is configured. The caller also binds `OperatorMediaOptions` (`src/Scout.Operator/FfmpegToolset.cs:12`) from `Scout:Operator` (`FfmpegPath`, `FontPath`, `PiperPath` and `VoicesPath` for the bundled voices, and `RhubarbPath` and `MouthsPath` for the animated character's lip sync (`src/Scout.Operator/FfmpegToolset.cs:30`, `:33`), which Scout Desktop sets as `SCOUT__OPERATOR__RHUBARBPATH` and `SCOUT__OPERATOR__MOUTHSPATH` (`tests/Scout.Host.Console.Tests/GrpcOperatorControlPlaneTests.cs:870`), `PresentersPath` for the built-in presenters and `FaceModelsPath` for the face models (`src/Scout.Operator/FfmpegToolset.cs:36`, `:39`), bound from `Scout:Operator` like the others (`tests/Scout.Host.Console.Tests/GrpcOperatorControlPlaneTests.cs:1236`), `src/Scout.Operator/FfmpegToolset.cs:24`, `:27`, which Scout Desktop sets as `SCOUT__OPERATOR__PIPERPATH` and `SCOUT__OPERATOR__VOICESPATH`, empty when it bundles none); the operator registers the process runner, the toolset, the bundled voices (`src/Scout.Operator/OperatorServiceCollectionExtensions.cs:70`), the named HTTP client `openverse` with a 10-second timeout and the User-Agent `Scout (+https://github.com/vitorafgomes/scout)` (`src/Scout.Operator/OperatorServiceCollectionExtensions.cs:35`) and the assembly stages itself, the runner with `TryAdd` so a test can put its own first (`src/Scout.Operator/OperatorServiceCollectionExtensions.cs:68`), and the built-in presenters, the ONNX runner, also with `TryAdd`, the mouth finder and the presenter job (`src/Scout.Operator/OperatorServiceCollectionExtensions.cs:79` to `:82`).

- **Publishing entry point:** `AddYouTubePublishing(IServiceCollection)` (`src/Scout.Operator/OperatorServiceCollectionExtensions.cs:91`): the executor, which runs the comment replies and holds too, the published check, the reach reports, the experiment runner, the learning loop, the seven scheduled jobs and the scheduler. [[pages/services/host-console]] calls it only when the YouTube plugin registered `IYouTubeWriteClient`, which it does only with the desktop sign-in. The upload category is `Scout:Operator:CategoryId`, `22` (People & Blogs) by default (`src/Scout.Operator/FfmpegToolset.cs:42`).

- **Publishing seam:** `IOperatorControlPlane.NextApprovedActionAsync` (`src/Scout.Operator/IOperatorControlPlane.cs:44`), which claims the oldest approved YouTube action, and `RecordActionAsync(action, outcome)` (`:52`), which consumes it; `ControlPlaneUnavailableException` (`:146`) tells an unreachable control plane apart from a refusal it words. `OperatorProjectState.Publication` (`:271`) carries `OperatorPublication` (`:173`) with its `OperatorSnapshot` (`:190`), `OperatorProposal` (`:213`) and `OperatorExperiment` (`:216`) records; `OperatorAction` (`:165`) mirrors `PendingAction`.
