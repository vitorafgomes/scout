- **Verified before use.** `verifyWhisperModel` (`ui/packages/main/src/worker/whisper-model.ts:94`) accepts a file only at the pinned size and then the pinned SHA-256, hashed as a stream. After a hash it writes `<file>.sha256` with the digest the file has, matching or not, the size and the mtime; the next check trusts that sidecar while the file's size and mtime are unchanged and compares its digest with the pin, so a 1.6 GB model is hashed once, not at every start, and a file at the pinned size with a wrong hash is not hashed again at every 4 s poll of Models, Transcription (since 2026-11-08). A file that fails either check is never loaded and stays on disk.
- **Which model.** `chooseWhisperModel` takes the `stt.model` vault value (`whisper-<variant>` or `<variant>`) when that model is verified, otherwise the first verified of large-v3-turbo, large-v3, small, base and tiny (`:45`); main reads `stt.model` with a failed read counting as none. Only main writes `stt.model` (since 2026-11-08): Use this saves it through `scout:whisper.useModel`, and `LocalModelsStore` keeps the window's selection without writing it, for the first download or when the selected model is removed (`ui/packages/renderer/src/app/core/local-models.store.ts:287`, `:303`), so the next start loads main's fallback by preference. With none set the best verified model is used. The worker reads the choice at start only, so since 2026-11-07 every change of the model it would load (a download, Use this, any store or delete of `stt.model`, removing the loaded model) restarts a running worker, deferred while a quick-ask answer runs or a live listen is open ([[pages/services/desktop-ui]], Whisper models).
- **Download.** `scout:whisper.downloadModel` (`ui/packages/main/src/ipc/whisper.ts:91`) refuses a `content-length` other than the pinned size before it reads or writes anything, hashes every chunk as it arrives, cuts off a body that runs past the pinned size, and after the last chunk requires the pinned size and digest; any failure, a reset or an HTTP error included, removes the `.partial` file and rejects, a digest mismatch with "whisper: checksum mismatch for <file>" (`:235`), the shape of `fetchPinned` in `ui/build/scripts/fetch-media-tools.mjs:51`. Only then is the file renamed into place and its sidecar written. Progress counts against the pinned size. Since 2026-11-08 a download that receives nothing for 60 s (`WHISPER_STALL_MS`, `:38`, a `setTimeout` reset at every chunk) aborts its request and rejects with "HuggingFace sent nothing for 60 s; the download stopped", and `scout:whisper.cancelDownload` stops the running download of a variant the same way with "the download was cancelled", with the code `whisper/download-cancelled` in the rejection so every window waiting on it shows it as cancelled (`:268`); either removes the `.partial` file, and the next Download starts a fresh request instead of joining the dead one. A write the disk refuses (no space, or a directory where the `.partial` file goes) rejects with the reason instead of escaping as an uncaught error in main (`:185`). Delete removes the model, its `.partial` and its sidecar.
- **Verified flag.** `scout:whisper.listInstalled` answers `{ variant, verified }` per model file present (`ui/packages/main/src/ipc/whisper.ts:311`, `WhisperInstalledModel` in `ui/packages/shared/src/ipc-contract.ts`), and Models → Transcription (route `llm?tab=transcription`; `sources/local-models` redirects there) marks only verified ones as downloaded (`refreshWhisper`, `ui/packages/renderer/src/app/core/local-models.store.ts:259`), so a file with a wrong hash shows Download again. When main cannot read the model folder it rejects (`ui/packages/main/src/ipc/whisper.ts:328`) instead of answering "nothing installed", so the renderer treats the state as unknown and the voice ask stays closed.
- **Catalog.** Since 2026-11-07 the renderer lists exactly main's pinned table: `scout:whisper.modelTable` (`ui/packages/main/src/ipc/whisper.ts`) returns each variant, file and exact size in main's order (tiny, base, small, large-v3-turbo, large-v3), and the renderer keeps only the title, note, memory and Recommended on Base per variant (`WHISPER_COPY`, `ui/packages/renderer/src/app/core/local-models.catalog.ts:21`). `scout:whisper.listInstalled` also answers `inUse`: while the worker runs, the model it loaded at its start (`loadedWhileRunning`, `ui/packages/main/src/worker/worker-restart.ts:179`), so a restart deferred under a live listen leaves the old model In use until it runs; while it is stopped, the variant `chooseWhisperModel` picks for the saved `stt.model`, the one the next start loads; and `preferred`, the saved choice, so Models, Transcription marks In use only what Scout uses and says "base is selected but not downloaded; Scout uses large-v3-turbo." when they differ and the saved choice is not downloaded, or "base is selected; Scout switches to it when it restarts." when it is (`ui/packages/main/src/ipc/whisper.ts:322`). `scout:whisper.useModel` saves `stt.model` and restarts a running worker ([[pages/services/desktop-ui]], Whisper models).
