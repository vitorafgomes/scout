# Scout Desktop - Visual Interface Design Document: Preface

This document specifies the complete visual design system for Scout Desktop, an Electron + Angular (21.x, Signals, standalone) provisioning application. The primary audience is a senior frontend developer implementing the Angular component library and screen layouts. All design decisions derive from the feasibility study, the Angular ADR, and Scout's product positioning as a read-only chatops assistant for engineering teams.
