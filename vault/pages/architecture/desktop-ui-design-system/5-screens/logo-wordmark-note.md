# Scout Desktop - Visual Interface Design Document: 5. Screens: Logo / Wordmark Note

Scout logo proposal: the wordmark is "Scout" in `text-2xl`, weight 700, using the UI font. The mono icon is a minimal SVG: a circle (representing a guild / server) with a simplified triangular crosshair inside — evoking scouting/reconnaissance. 24 × 24px at 1x. Rendered in `accent` colour on `surface-raised` or as white on dark backgrounds. No gradients, no shadows on the mark.
